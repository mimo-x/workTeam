# 产品愿景地图

## 当前产品方向

本产品希望让用户在本地运行自己的 Agent，并通过多人协作把不同用户的 Agent 连接起来。用户可以在群聊中发起请求，Agent 在所属用户的本地环境中处理工作，并把结果或协作过程带回群聊。

当前先聚焦两个相互关联的愿景：共享 Agent 的执行能力，以及共享 Agent 的工作上下文。

## 愿景一：跨用户调用 Agent

多个用户可以在同一个群聊中调用彼此本地运行的 Agent。被调用的 Agent 在所属用户的本地环境中处理任务，完成后把结果返回原群聊，让参与者都能看到结果。

### 价值

用户不需要把本地代码、工具和运行环境迁移到云端，就可以请求其他用户的 Agent 提供分析、编码、审查或其他协作能力。

### 关注点

- Agent 有明确的所属用户和本地运行位置。
- 群聊成员能够识别当前可调用的 Agent。
- 调用请求能够路由到正确用户的桌面端。
- Agent 的执行结果能够回到原群聊。
- Agent 所属用户能够控制谁可以调用自己的 Agent，以及哪些操作需要确认。

## 愿景二：跨 Agent 共享上下文

用户可以在群聊中让自己的本地 Agent 与其他用户的 Agent 交流工作上下文，并把完成协作所需的信息传递给其他 Agent，使多个 Agent 能够共同推进一个任务。

### 价值

不同用户的 Agent 可以利用各自拥有的本地能力和工作环境协作，而不只是分别回答相互孤立的问题。

### 关注点

- Agent 能够理解当前群聊、任务和其他 Agent 的身份。
- 上下文共享范围是明确且可控制的。
- Agent 可以在用户授权下把必要信息传递给其他 Agent。
- 多轮交流不会丢失任务目标、历史消息和执行状态。
- 协作过程能够被群聊参与者观察和追踪。
