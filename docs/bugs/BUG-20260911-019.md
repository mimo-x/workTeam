# 开发模式退出桌面 App 时出现清理错误

## 复现 Case

Given 用户使用 `pnpm run dev` 启动桌面 App
When 点击窗口关闭或在终端按 `Ctrl+C`
Then 应等待资源清理完成后安静退出

实际结果：OpenIM 原生 SDK、Codex 或开发进程退出时可能输出错误日志。

## 修复

增加幂等退出协调器，按顺序释放资源；单项清理失败时继续处理后续资源。

## 验证

自动化退出协调器测试、类型检查和 Lint 已通过；macOS 真机开发模式手动验证待完成。
