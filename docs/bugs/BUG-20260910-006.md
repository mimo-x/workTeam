# macOS Electron 启动后无窗口并 SIGABRT

## 现象

Electron 44.2.0 在 macOS 26.6.1 上启动后没有可见窗口，系统报告 `Abort trap: 6`，崩溃栈位于 AppKit `RegisterApplication`。

## 复现 Case

Given macOS 26.6.1 和 Electron 44.2.0
When 执行 `npm run dev`
Then Electron 进程退出或保持无窗口，桌面端无法操作

## 根因

Electron 在 JS 执行前调用 macOS AppKit `RegisterApplication` 时无法访问 `launchservicesd`，触发 `SIGABRT`。官方 Electron issue #52815 确认这是 macOS 26 受限启动环境问题；裸 Electron 也能复现，因此不是项目业务代码或 OpenIM SDK 引起。

## 处理结论

不能在应用 JS 中捕获这个崩溃。应从 macOS 正常 Terminal/Finder/Launch Services 启动桌面端，避免在受限 Codex/cmux 沙箱中直接启动 Electron GUI。
