# 消息列表右键菜单缺少置顶与删除

## 复现 Case

Given 用户进入消息流并看到左侧会话列表
When 用户右键任意私聊、群聊或 Task 会话
Then 没有出现置顶和删除操作

## 环境与根因

当前会话条目仅渲染为普通按钮，UI 重构后没有挂载 shadcn ContextMenu，也没有维护会话列表的置顶和隐藏偏好。

## 预期与验证

每个会话条目提供置顶或取消置顶、删除会话两项操作。置顶会话优先排列；删除操作经过确认后从本机消息列表隐藏且不破坏群、Task 或远端消息，新消息到达后会话自动恢复。自动化 Case 覆盖菜单渲染、置顶排序与删除后的恢复行为。

修复后已在 Electron 亮色主题中实际验证右键菜单、置顶排序、取消置顶和删除确认框。52 项桌面测试、lint、typecheck、build 与 Bug 门禁通过。
