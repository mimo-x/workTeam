# 消息、通讯录和 Task 页面未继承亮色主题

## 复现 Case

Given 用户在设置中心选择亮色主题
When 用户打开消息流、通讯录与 Agent 或 Task 面板
Then 页面内部列表、卡片、输入区和状态组件仍以硬编码暗色显示

## 环境与证据

实际 Electron 截图显示应用主侧栏为亮色，但消息页、通讯录顶栏和 Task 卡片仍为深灰或黑色。源码检查确认这些渲染区使用固定颜色类，绕过了全局主题变量。

## 预期与验证

消息页、通讯录和 Task 面板使用语义主题 token，同一套结构自动适配亮色和暗色。修复后相关页面不再使用固定暗色背景、白色透明边框或 zinc 正文色；测试、Lint、类型检查和构建均通过。
