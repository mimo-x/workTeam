# 后台同步群中提及自己的 Agent 后没有回复

## 现象

用户在群 `67aa59ad-e315-4f2f-b3f6-63f3216a863f` 中发送包含自己 Agent 提及的普通聊天消息，用户消息能够显示，但 Agent 没有产生回复。

## 复现 Case

Given 用户已登录多用户后台，群 `67aa59ad-e315-4f2f-b3f6-63f3216a863f` 是后台同步群，且群内包含当前用户拥有的本机 Agent
When 用户在群聊回复模式发送一条 `@` 该 Agent 的消息
Then 消息应通过 OpenIM 发送并在当前桌面只为被提及的自有本机 Agent 创建一次 Run，完成后将 Agent 回复发布回原群

## 预期结果

后台同步群中的普通 `@Agent` SHALL 保持聊天语义，并触发当前用户拥有且运行位置为本机的目标 Agent 回复；不得因此创建 Task，也不得在当前电脑执行其他用户拥有的 Agent。

## 实际结果

用户消息经 OpenIM 发送和本地写入，但当前桌面没有为目标 Agent 创建 Run，因此群内没有 Agent 回复。

## 环境

- macOS Electron 桌面端
- 工作区：`/Users/mvbj0705/dev/agent-team`
- 房间 ID：`67aa59ad-e315-4f2f-b3f6-63f3216a863f`
- 房间来源：多用户后台同步群
- 消息模式：群聊回复

## 原始日志

```text
无显式运行时错误；发送完成后没有 pending/streaming Agent 消息，也没有 Agent Run。
```

## 请求与运行标识

- Room：`67aa59ad-e315-4f2f-b3f6-63f3216a863f`
- Session：未创建
- Run：未创建
- Provider / Model：未进入 Runtime，无法生成

## 根因

后台同步房间的发送分支将提及目标传给 OpenIM，但调用 `ingestExternalMessage` 时省略了 `model`、`targetAgentIds` 和 `triggerAgents`，因此消息只进入本地时间线，没有创建 Run。即使启用本机 Run，原 Agent Gateway 也只读取兼容模式的共享密钥，无法安全发布后台同步群的 Agent 回复；同时主进程会优先按正文重新解析提及，可能越过渲染层的自有 Agent 过滤并扩大执行目标。

## 修复说明

- 后台同步群仅把当前用户拥有且执行位置为本机的被提及 Agent 作为精确触发目标，并传递当前模型。
- 外部消息显式提供的 `targetAgentIds` 成为权威调度集合，正文中的其他提及不能扩大执行范围。
- 新增鉴权的后台 Agent 回复接口；只允许房间成员以其自有、已入群、本机执行的 Agent 身份发布，并以 delivery ID 幂等写入 OpenIM Outbox。
- 兼容模式仍使用已有 Agent Gateway，后台同步群则通过登录态调用后台接口。
