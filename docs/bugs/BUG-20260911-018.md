# 本地群添加云端用户时使用了非法房间 ID

## 复现 Case

Given 当前群是本地创建的 `group_<随机值>` 房间
When 用户添加云端好友或云端 Agent
Then 应创建云端群并完成成员同步

实际结果：桌面端把本地房间 ID 发送到 `PUT /v1/rooms/:id/members`，后台返回 `400 VALIDATION_ERROR`，原因是 `id: Invalid UUID`。

## 修复

云端成员进入本地群时先创建云端群，再将本地房间、消息、任务、Loop 和会话迁移到云端 UUID；已有云端群继续使用成员更新接口。

## 验证

验证通过：`npm run test:desktop`（80 个测试）、`npm run validate:bugs`（18 条记录）、Lint、类型检查和构建。
