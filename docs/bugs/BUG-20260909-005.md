# OpenIM 启动窗口导致部署脚本输出误导性解析错误

## 现象

OpenIM 重启后脚本请求被 reset，随后 Python 报 `JSONDecodeError`，用户无法判断是服务尚未就绪还是认证失败。

## 复现 Case

Given OpenIM 容器刚被重新启动
When deploy.sh 在 API 就绪前请求管理凭证
Then 脚本安静重试，并在最终失败时显示 OpenIM 阶段诊断

## 根因

脚本没有独立的 API 就绪探测，且空响应直接交给 JSON 解析器。
