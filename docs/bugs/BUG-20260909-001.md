# Refresh Token 并发失效与 OpenIM Token 错误

## 现象

桌面端同时触发多个后台请求时，服务端出现一个刷新成功和一个 `INVALID_REFRESH_TOKEN`；OpenIM 会话获取返回 `TokenMalformedError`。

## 复现 Case

Given 桌面端保存了有效的 refresh token
When 启动时多个初始化流程同时请求后台 API
Then refresh 请求只能执行一次，其他请求复用同一个结果

Given OpenIM 管理 Token 格式错误
When 请求 `/v1/im/session`
Then API 返回可识别的 OpenIM 错误，而不是丢失原因的通用 500

## 根因

客户端没有合并并发 refresh 请求；服务端将 OpenIM 原始错误统一转换成了 `INTERNAL_ERROR`。

## 修复与验证

已增加 refresh 单飞、失效 Token 清理和 OpenIM 错误透传。验证命令见关联 OpenSpec change 的任务记录。
