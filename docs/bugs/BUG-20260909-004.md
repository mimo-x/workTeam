# OpenIM v3.8 健康检查误报 unhealthy

## 现象

服务器中 `openim-server` 和 `openim-chat` 显示 `unhealthy`，健康检查日志为 `Health check exceeded timeout (1m0s)`；容器内执行 `mage check` 又提示 `go: executable file not found`。

## 复现 Case

Given OpenIM v3.8 运行镜像没有 Go
When Docker 执行默认 `mage check` 健康检查
Then 容器被标记为 unhealthy，即使部署脚本需要调用的 API 可能仍可用

## 根因

上游运行镜像的健康检查依赖构建工具 Go，运行镜像没有该依赖；部署流程没有把真实 API 探活作为唯一判断依据。

## 修复与验证

待通过 `fix-openim-healthcheck` change 将探活切换到 OpenIM 管理 API，并完成一键部署验收。
