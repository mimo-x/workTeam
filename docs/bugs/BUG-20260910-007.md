# OpenIM 登录前未创建数据库目录

## 复现 Case

Given 首次启动，OpenIM 本地数据目录尚不存在
When 桌面端获取 OpenIM 配置并登录
Then SDK 报 10006、unable to open database file: no such file or directory

## 环境与根因

实际 Electron 页面与文件系统检查共同确认；云端和手动配置入口均缺少 mkdir。日志仅记录错误特征，不复制用户地址或凭证。

## 预期与验证

两个入口返回前创建目录，保留已有文件；路径冲突明确失败。修复前两个 Case 均以 ENOENT 失败，修复后通过。35 项桌面测试、lint、typecheck、build、Bug 校验及本 change 严格校验通过。

实际启动 Electron 后通过其调试接口读取真实界面：数据库错误消失，消息页显示 OpenIM 已连接，通讯录可正常打开。此证据仅覆盖本地目录修复，不代表所有产品功能已验收。
