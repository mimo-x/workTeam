# Agent Host 旧设备 ID 导致 API 崩溃

## 现象

Host 使用已不存在的 deviceId 注册时，API 日志出现 `DEVICE_NOT_FOUND`，Node 进程退出并被 Docker 反复重启，桌面端随后收到 `ECONNREFUSED:8790`。

## 复现 Case

Given 数据库中不存在客户端携带的旧 deviceId
When Host 发送 `host.register`
Then 服务端创建新设备并完成注册，API 进程保持运行

## 根因

异步 WebSocket handler 没有 await `registerHost`，注册 Promise rejection 逃出 try/catch；旧设备更新失败也没有恢复分支。

## 修复与验证

已增加旧设备自动注册和异步错误隔离，并通过 `services/chat-api/src/realtime.test.ts` 验证。
