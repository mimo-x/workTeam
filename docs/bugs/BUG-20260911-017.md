# Codex 会话列表 IPC 没有主进程处理器

## 复现 Case

Given 桌面端打开 Codex 工作区
When 渲染层调用 `window.codex.listThreads`
Then 主进程应返回会话列表

实际结果：`No handler registered for 'codex:list-threads'`。

## 修复

注册会话读写、Skills、MCP 和 Worktree 相关 IPC，并补充静态回归测试。

## 验证

验证通过：`npm run test:desktop`（80 个测试）、`npm run validate:bugs`（18 条记录）、Lint、类型检查和构建。
