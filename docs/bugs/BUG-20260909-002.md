# OpenIM 管理 Token 无法获取用户会话

## 现象

请求 `/v1/im/session` 时，API 日志出现 `TokenMalformedError`，客户端只看到 `500 INTERNAL_ERROR` 或 `fetch failed`。

## 复现 Case

Given API 配置了格式错误的 OpenIM 管理 Token
When 桌面端请求 `/v1/im/session`
Then 服务端日志记录 `TokenMalformedError`，API 返回包含具体 OpenIM 原因的错误

## 根因

OpenIM 下游错误没有在 API 边界转换为带具体原因的业务错误。

## 修复与验证

已将 OpenIM Provider 错误映射为 `OPENIM_ERROR`，并保留具体错误消息和 requestId。
