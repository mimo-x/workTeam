# 好友消息与我的消息显示在同一侧

## 复现 Case

Given 群聊或私聊中同时存在当前用户与好友消息
When 消息列表渲染 OpenIM 好友消息
Then 好友消息因为 `senderType` 同为 `user` 而错误显示在右侧

## 环境与根因

`MessageRow` 使用 `senderType === "user"` 判断当前用户，但 `user` 表示非 Agent 用户类型，既包含当前用户也包含好友。所有会话共用该渲染器，因此群聊和私聊均受影响。

## 预期与验证

仅 `senderId === "local_user"` 的消息显示在右侧；好友与 Agent 消息显示在左侧；系统消息保持居中。自动化 Case 覆盖身份判断和共享消息渲染器。

修复后好友私聊数据已在 Electron 中复核，好友使用联系人头像并显示在左侧，当前用户显示在右侧。54 项桌面测试、lint、typecheck、build 与 Bug 门禁通过。
