# 消息、通讯录和 Task 页面未继承亮色主题

## 复现 Case

Given 用户在设置中心选择亮色主题
When 用户打开消息流、通讯录与 Agent 或 Task 面板
Then 页面内部列表、卡片、输入区和状态组件仍以硬编码暗色显示

## 环境与证据

实际 Electron 截图显示应用主侧栏为亮色，但消息页、通讯录顶栏和 Task 卡片仍为深灰或黑色。源码检查确认这些渲染区使用 `bg-[#...]`、`bg-black/*`、`border-white/*` 和 `text-zinc-*`，绕过了全局主题变量。

## 预期与验证

消息页、通讯录和 Task 面板使用 `background`、`card`、`muted`、`border`、`foreground`、`primary` 等语义 token，同一套结构自动适配亮色和暗色。回归测试需要阻止三个页面重新引入固定暗色类，并通过真实 Electron 亮色界面复核。

修复后消息页、通讯录和 Task 面板不再包含固定暗色背景、白色透明边框或 zinc 正文色。通讯录复用 shadcn `Card`、`Input`、`Button` 和 `Badge`；Task 面板复用完整 Card 结构、Button 与 Badge，页面结构和业务行为保持不变。45 项桌面测试、lint、typecheck、build 与 Bug 门禁通过。

Electron 开发进程已使用最新代码重启且无启动错误。当前自动化环境无法绑定该 Electron 原生窗口；浏览器直开渲染地址也因缺少 preload API 无法替代桌面验收，因此亮色视觉复核保留为人工确认项。
