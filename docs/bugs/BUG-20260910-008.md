# OpenIM 好友私聊发送失败且群聊无法提及好友

## 现象

桌面端显示 OpenIM 已连接并能打开好友私聊，但发送文本后出现 JavaScript 属性赋值错误，消息没有进入会话。群聊可以管理好友成员，但输入 `@` 时只搜索 Agent，无法选择好友作为提及目标。

## 复现 Case

### 好友私聊

Given Electron 桌面端已登录，OpenIM 状态为已连接，且好友 `xuxin` 已存在
When 打开 `xuxin` 好友私聊并发送一条文本消息
Then 消息应显示在私聊中且不应出现错误

实际结果：页面显示 `Cannot create property 'ex' on string ''`。

### 群聊提及好友

Given 好友已加入当前 OpenIM 群聊
When 在群聊输入 `@` 并尝试选择好友后发送消息
Then 消息应携带好友 OpenIM ID 作为 at 目标，且不创建 Agent Task

实际结果：提及候选只包含 Agent，无法选择好友。

## 环境与原始错误

- 平台：macOS Electron 开发模式
- Runtime：OpenIM Electron SDK `3.8.3-patch.15.1`
- 原始 UI 错误：`Cannot create property 'ex' on string ''`
- 调试确认：`createTextMessage` 返回 `{ errCode: 0, data: "" }`；直接给 `sendMessage` 传入最小合法文本消息对象可成功返回消息。

## 根因

渲染进程假定原生 SDK 消息工厂返回 `MessageItem`，未校验空字符串就写入 `created.data.ex`。群聊提及逻辑只从 `roomAgents` 构建候选和目标列表，忽略了 `roomHumans`。
