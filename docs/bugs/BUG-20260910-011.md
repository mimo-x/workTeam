# Agent 设置弹窗未继承亮色主题

## 复现 Case

Given 用户在设置中心选择亮色主题
When 用户从通讯录创建或编辑 Agent
Then Agent 设置弹窗、列表、表单和操作区仍显示固定暗色

## 环境与根因

实际 Electron 截图显示应用外壳为亮色，但 Agent 设置弹窗仍为黑色。`AgentSettings` 使用固定十六进制背景、black/white 透明色和 zinc 文本色，并通过自定义 Modal 和原生表单绕过主题组件。

## 预期与验证

弹窗使用 shadcn Dialog、Input、Textarea 与 Button，并通过语义 token 同时适配亮色和暗色。自动化回归 Case 阻止该组件重新引入固定暗色类。

修复后 AgentSettings 使用 shadcn Dialog、Input、Textarea 和 Button，原生下拉框也统一使用语义主题 token。Agent 列表、邀请提示、错误提示及底部操作区均不再包含固定暗色类。49 项桌面测试、lint、typecheck、build 与 Bug 门禁通过。
