# 通讯录创建 Agent 入口没有创建新草稿

## 复现 Case

Given 用户在桌面端通讯录页面
When 点击页面顶部“创建 Agent”
Then Agent 设置弹窗应打开并选中新 Agent 草稿

## 实际现象

页面顶部按钮只调用 `onEditAgents()`，弹窗默认选中已有 Agent。用户必须再次点击弹窗左侧的“创建 Agent”才能真正新增草稿，第一次操作与按钮文案不一致。

## 环境与根因

桌面端 Electron 渲染器，`src/renderer/src/team-chat.tsx`。`AgentSettings` 只有 `initialAgentId` 参数，没有创建模式；通讯录入口没有向弹窗传递创建意图。

## 修复说明

增加创建模式初始化逻辑，通讯录入口打开弹窗时自动追加并选中新 Agent 草稿；弹窗内部的创建按钮复用相同的草稿生成函数，并继续限制最多 24 个本地 Agent。

## 验证结果

BDD 用例覆盖通讯录入口、有效草稿、上限、类型和保存恢复；修复后 66 个桌面测试、Lint、类型检查、构建和 Bug 门禁全部通过。Electron GUI 手动复核未在当前受限启动环境执行；该环境已有 `BUG-20260910-006` 记录的 macOS Electron 启动崩溃。
