## Why

登录后台后保存 Agent 会调用 `POST /v1/agents`。后台返回了字段级校验详情，但桌面端只保留 `请求参数不正确。`，用户无法知道是提及名称、Runtime Endpoint 还是其他字段不符合规则。已有本地保存测试没有覆盖这条云端请求路径。

## What Changes

- 抽出云端 Agent 请求体构造和前置校验。
- 保存前校验后台已知的字段约束，并在界面显示可操作的中文错误。
- 保留后台返回的 Zod 字段级校验详情。
- 增加云端请求体、非法字段和错误详情的 BDD 回归用例。

## Impact

只影响 Agent 云端保存失败时的校验和错误提示，不改变后台 Agent 数据结构或本地 Agent 执行逻辑。
