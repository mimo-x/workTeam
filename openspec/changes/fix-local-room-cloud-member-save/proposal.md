## Why

已有本地群包含带云端身份的 Agent 时，群成员保存逻辑会把本地房间误判为云端房间，并把 `local-agent-team` 作为后台 UUID 路径参数，导致保存失败。

## What Changes

- 使用房间是否已经存在及其同步来源共同决定群组保存目标。
- 已有本地群始终调用本地更新，不请求云端房间成员接口。
- 已有云端群继续调用云端更新；新建群保留按云端模式和远端成员选择创建云端群的行为。
- 增加覆盖本地群、云端群和新建群分支的 BDD 回归 Case。

## Impact

仅修改桌面端群组保存目标的决策逻辑，不改变后端 API、房间数据结构或现有 UI。
