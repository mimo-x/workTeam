## Why

通讯录外层的“创建 Agent”按钮只打开了 Agent 设置弹窗，却默认选中已有 Agent。用户需要再次点击弹窗侧栏中的“创建 Agent”才会出现新草稿，手动创建流程因此无法按按钮文案完成。

## What Changes

- 让通讯录“创建 Agent”入口以创建模式打开设置弹窗。
- 创建模式自动添加并选中新 Agent 草稿。
- 让弹窗内部创建按钮和通讯录入口复用同一套草稿生成逻辑。
- 增加覆盖入口、草稿、类型和上限行为的 BDD 回归用例。

## Impact

仅影响桌面端 Agent 设置入口和草稿初始化，不改变已保存 Agent 的数据结构或 Runtime 执行协议。
